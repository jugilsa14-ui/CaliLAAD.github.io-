# CALI.LAAD

Web de calistenia de fuerza basada en el método LAD: simulador de torques, calculadora de carga (LAD-Au e INOL), registro de sesiones y evolución en el tiempo.

- `index.html`: la web completa, un solo archivo.
- `CNAME`: dominio propio (calilaad.com) para GitHub Pages.

Estado: versión 1. Los datos se guardan en el navegador de cada usuario (con exportar/importar). Próximo paso: cuentas de usuario y datos en Supabase.
